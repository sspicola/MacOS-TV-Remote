TV Remote puts an Apple TV remote and app launcher in your Mac's menu bar.

- Navigate, select, go back or home, and play or pause.
- Adjust volume through Apple TV and your existing TV/audio setup.
- Switch between paired Apple TVs on your network.
- Browse installed apps, search, and launch one with a click.

Download `TV-Remote-0.3.0-universal.zip`, unzip it, and move `TV Remote.app` to
Applications. The same download supports Apple silicon and Intel Macs running
macOS 14 or later. Allow Local Network access, choose your TV, and enter the code
displayed on it.

This release is ad-hoc signed and has not been notarized by Apple. After trying
to open it, use System Settings → Privacy & Security → Open Anyway if macOS
blocks it and you trust this download. Apple's [first-open instructions](https://support.apple.com/en-us/102445)
explain the exception. You can also [build from source](https://github.com/sspicola/MacOS-TV-Remote#build-from-source).

The `.sha256` file contains the archive checksum. To verify it, put both files
in the same folder and run:

```sh
shasum -a 256 -c TV-Remote-0.3.0-universal.zip.sha256
```

TV Remote uses an unofficial Apple TV protocol. Compatibility can change with
tvOS updates. Volume support depends on the connected TV and audio equipment.
